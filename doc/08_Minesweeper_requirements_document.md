# マインスイーパーゲーム 要件定義書

## 1. ゲーム概要

### 1.1 ゲーム名
マインスイーパー（Minesweeper / 地雷除去ゲーム）

### 1.2 ゲームの説明
グリッド内に隠された地雷を避けながら、すべての安全なマスを開けるクラシックなパズルゲーム。各マスには周囲8マスに存在する地雷の数が表示され、その情報を手がかりに論理的に地雷の位置を推理します。旗を立てて地雷をマークし、すべての安全なマスを開ければクリアです。

### 1.3 ゲームの目的
- 地雷を踏まずにすべての安全なマスを開く
- 論理的推理で地雷の位置を特定する
- 最速クリアタイムを目指す
- 推理力と集中力を鍛える

### 1.4 プレイ人数
1人

### 1.5 想定プレイ時間
- 初級: 1～3分
- 中級: 3～8分
- 上級: 8～20分
- カスタム: 難易度により変動

## 2. ゲームルール

### 2.1 基本ルール
1. **グリッド構成**: 長方形のマスで構成されたフィールド
2. **地雷配置**: ランダムに地雷が配置されている（最初のクリックは必ず安全）
3. **マス開放**:
   - 左クリックでマスを開く
   - 数字が表示される（周囲8マスの地雷数）
   - 周囲に地雷がない場合は自動で広範囲が開く
4. **旗立て**: 右クリックで地雷と推測される場所に旗を立てる
5. **地雷を踏んだら**: ゲームオーバー
6. **クリア条件**: すべての安全なマスを開く

### 2.2 操作方法
#### マウス操作
- **左クリック**: マスを開く
- **右クリック**: 旗を立てる/外す
- **中クリック（両クリック）**: 周囲の旗が正しければ一括オープン（コード機能）

#### タッチ操作
- **タップ**: マスを開く
- **長押し**: 旗を立てる/外す

#### キーボード操作
- **矢印キー**: カーソル移動
- **スペース/Enter**: マスを開く
- **F**: 旗を立てる/外す

### 2.3 数字の意味
- **0（空白）**: 周囲8マスに地雷なし  自動で周囲を開く
- **1～8**: 周囲8マスに存在する地雷の数

### 2.4 難易度レベル

#### 初級（Beginner）
- グリッド: 9×9（81マス）
- 地雷数: 10個
- 地雷密度: 約12.3%

#### 中級（Intermediate）
- グリッド: 16×16（256マス）
- 地雷数: 40個
- 地雷密度: 約15.6%

#### 上級（Expert）
- グリッド: 30×16（480マス）
- 地雷数: 99個
- 地雷密度: 約20.6%

#### カスタム（Custom）
- グリッド: 5×5～50×50（ユーザー指定）
- 地雷数: ユーザー指定
- 地雷密度: 最大40%まで

### 2.5 勝利条件
- すべての地雷以外のマスを開く
- または、すべての地雷に正しく旗を立てる

### 2.6 敗北条件
- 地雷のあるマスを開いてしまう

## 4. 機能要件

### 4.1 フィールド生成機能
#### 地雷配置アルゴリズム
1. **最初のクリック保護**: 最初にクリックした場所とその周囲8マスには地雷を配置しない
2. **ランダム配置**: Fisher-Yatesシャッフルアルゴリズムで地雷を配置
3. **数字計算**: 各マスの周囲8マスをチェックして地雷数をカウント

### 4.2 マス操作機能
#### マスを開く
- 未開封マスをクリック
- 地雷の場合  ゲームオーバー
- 数字の場合  数字を表示
- 0の場合  連鎖的に周囲を開く（再帰処理）

#### 旗を立てる
- 右クリック/長押しで旗を立てる
- 再度右クリックで疑問符（?）に変更（オプション）
- 再度右クリックで旗を外す
- 残り地雷数を更新

#### コード機能（両クリック）
- 開いたマスの周囲に正しい数の旗が立っていれば
- 周囲の未開封マスを一括オープン
- 時短テクニック

### 4.3 自動開放機能
#### 連鎖オープン
- 0のマスを開いた時
- 再帰的に周囲8マスを開く
- 数字が出るまで続ける
- フラッドフィルアルゴリズム

### 4.4 タイマー機能
- 最初のクリックでスタート
- 秒単位でカウントアップ
- 999秒でストップ
- ゲーム終了で停止

### 4.5 地雷カウンター機能
- 総地雷数から旗の数を引いた値を表示
- 負の値も表示可能（過剰に旗を立てた場合）
- 3桁表示（001～999）

### 4.6 リセット機能
- スマイルボタンクリックで新しいゲーム
- 同じ難易度で再スタート
- タイマーと地雷カウンターをリセット

### 4.7 ゲーム状態管理
#### 状態遷移
1. **未開始**: ゲーム生成直後
2. **プレイ中**: 最初のクリック後
3. **クリア**: すべての安全マスを開いた
4. **ゲームオーバー**: 地雷を踏んだ

### 4.8 記録保存機能
- ベストタイム記録（難易度別）
- プレイ回数・クリア回数
- 勝率統計
- ローカルストレージに保存

### 4.9 設定機能
#### ゲーム設定
- **旗マーク方式**: 旗のみ / 旗疑問符なし
- **サウンド**: ON/OFF
- **アニメーション**: ON/OFF
- **コード機能**: 有効/無効
- **最初のクリック保護**: ON/OFF

### 5.3 主要アルゴリズム
#### 地雷配置
```javascript
function placeMines(grid, firstClickX, firstClickY, mineCount) {
  const safeZone = getSafeZone(firstClickX, firstClickY);
  const availableCells = getAllCells().filter(c => !safeZone.includes(c));
  const minePositions = shuffle(availableCells).slice(0, mineCount);
  minePositions.forEach(pos => grid[pos.y][pos.x].isMine = true);
}
```

#### 連鎖オープン（フラッドフィル）
```javascript
function floodFill(x, y) {
  if (outOfBounds(x, y) || isOpen(x, y)) return;
  
  openCell(x, y);
  
  if (getNeighborMines(x, y) === 0) {
    for (let dx = -1; dx <= 1; dx++) {
      for (let dy = -1; dy <= 1; dy++) {
        if (dx !== 0 || dy !== 0) {
          floodFill(x + dx, y + dy);
        }
      }
    }
  }
}
```

#### 勝利判定
```javascript
function checkWin() {
  const totalCells = width * height;
  const safeCells = totalCells - mineCount;
  return openCount === safeCells;
}
```

## 6. UI/UXデザイン

### 6.1 カラースキーム
#### セルの色
- **未開封**: 明るいグレー（#bdbdbd）、立体的な影
- **開封済み**: 白または薄いグレー（#e0e0e0）
- **地雷（ゲームオーバー時）**: 赤背景（#ff5252）
- **踏んだ地雷**: 濃い赤背景（#d32f2f）
- **間違った旗**: 黄色背景（#ffeb3b）

#### 数字の色
- **1**: 青（#1976d2）
- **2**: 緑（#388e3c）
- **3**: 赤（#d32f2f）
- **4**: 紫（#7b1fa2）
- **5**: 茶色（#795548）
- **6**: シアン（#00acc1）
- **7**: 黒（#000000）
- **8**: グレー（#757575）

#### その他
- **旗**: 赤旗アイコン（🚩）
- **地雷**: 爆弾アイコン（💣）
- **スマイル**: 通常😊、勝利🎉、敗北😵

### 6.2 セルデザイン
- **サイズ**: 20px × 20px（デスクトップ）、30px × 30px（モバイル）
- **ボーダー**: 未開封時は立体的な影（凸）
- **フォント**: 太字、中央揃え
- **アイコン**: Unicode絵文字またはFont Awesome

### 6.3 アニメーション
- **マス開封**: フェードイン（0.1秒）
- **連鎖オープン**: 波紋状に順次開く
- **旗を立てる**: スケールアップ（0.2秒）
- **ゲームオーバー**: 全地雷が順次表示される
- **クリア**: 紙吹雪エフェクト

### 6.4 レスポンシブデザイン
#### デスクトップ（1200px以上）
- セルサイズ: 20px × 20px
- 上級もフルサイズで表示（600px × 320px）

#### タブレット（768px～1199px）
- セルサイズ: 25px × 25px
- グリッドサイズに応じてスクロール

#### スマートフォン（767px以下）
- セルサイズ: 30px × 30px
- 初級・中級のみ推奨
- 上級は横スクロール対応

### 6.5 タッチ最適化
- **長押し検出**: 500ms
- **誤タップ防止**: 最小タップ間隔100ms
- **スワイプスクロール**: 大きいグリッドで有効
- **ズーム機能**: ピンチイン/アウト対応

### 6.6 アクセシビリティ
- キーボード完全操作対応
  - 矢印キーで移動
  - スペース/Enterで開く
  - Fキーで旗
- スクリーンリーダー対応
- 色覚障害対応（数字に加えてパターン表示オプション）
